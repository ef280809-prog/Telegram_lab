01 — CONOCE LA PLATAFORMA

¿Qué es Telegram?

Telegram es una aplicación de mensajería instantánea basada en la nube que permite intercambiar mensajes, archivos y contenido multimedia, además de crear grupos, canales y bots.

✈
PLATAFORMA

Comunicación rápida y multidispositivo

Permite acceder a conversaciones desde diferentes dispositivos. Los chats en la nube se sincronizan mediante la cuenta del usuario, facilitando la continuidad de la comunicación.

MensajesArchivosSincronización
➤
◉
COMUNIDADES

Grupos y canales

Los grupos facilitan conversaciones entre miembros; los canales permiten difundir publicaciones a una audiencia. Cada formato responde a necesidades distintas.

⚡
AUTOMATIZACIÓN

Los bots

Son programas que interactúan con usuarios a través de Telegram y pueden responder, ofrecer información o integrarse con servicios externos.

02 — AUTOMATIZACIÓN INTELIGENTE

Un bot es más que
una respuesta automática.

Un bot de Telegram es una cuenta especial controlada por software. Puede recibir actualizaciones y ejecutar acciones según la lógica que programe su creador.

01

Recibe una actualización

Telegram entrega al bot eventos como mensajes nuevos o comandos enviados por el usuario.

02

Procesa la información

El programa interpreta los datos, valida la solicitud y determina qué acción realizar.

03

Devuelve una respuesta

El bot usa los métodos de la API para responder, enviar contenido o interactuar con otros sistemas.

04

Registra y controla

Un backend puede aplicar permisos, límites, registros técnicos y manejo de errores.

03 — CONEXIÓN TÉCNICA

¿Cómo funciona la
Telegram Bot API?

La Bot API es una interfaz HTTP que permite a los desarrolladores comunicarse con los bots de Telegram. Los métodos reciben solicitudes y devuelven respuestas estructuradas en JSON.

MÉTODO DE ENVÍO

sendMessage

Este método envía texto a un chat identificado por su Chat ID. La solicitud se realiza mediante HTTP POST con los parámetros necesarios.

  • chat_id: identificador del chat destinatario.
  • text: contenido textual del mensaje.
  • parse_mode: opcional, para interpretar formatos compatibles.

04 — PROTECCIÓN Y RESPONSABILIDAD

Seguridad desde
el primer carácter.

Una integración funcional también debe proteger credenciales, validar entradas y limitar el uso indebido. Estas medidas son esenciales antes de publicar una aplicación.

01
🔑

Protege el token

Guárdalo como variable de entorno en el servidor. Nunca lo escribas en archivos públicos, código frontend o capturas.

CREDENCIALES
02
🛡️

Valida cada entrada

Comprueba el formato del Chat ID, la longitud del mensaje y los permisos antes de procesar la solicitud.

VALIDACIÓN
03
🚦

Evita el abuso

Implementa autenticación, límites de solicitudes y controles para impedir envíos masivos o no autorizados.

CONTROL DE USO
04
🔍

Trata errores con cuidado

No muestres secretos ni trazas internas. Registra lo necesario y presenta mensajes claros para el usuario.

MANEJO DE ERRORES
⚠
Regla de oro

El token funciona como una contraseña del bot. Si se filtra, revócalo o genera uno nuevo mediante BotFather y actualiza la variable secreta del servidor.

GitHub Pages no ejecuta Node.js. Para que el envío funcione desde una web pública, el backend debe estar desplegado y la página debe llamar a su endpoint HTTPS. No coloques el token en el frontend.

07 — PREGUNTAS FRECUENTES

Resolvemos tus
dudas técnicas.

Conceptos esenciales para comprender los requisitos y solucionar problemas frecuentes durante la práctica.

¿Qué es BotFather y para qué sirve?+

Es el bot oficial de Telegram que permite crear y administrar bots. Mediante comandos como /newbot entrega la configuración inicial y el token de acceso.

¿Por qué el usuario debe iniciar el bot primero?+

Un bot no puede iniciar por sí solo una conversación privada con una persona que nunca lo ha contactado. El usuario debe abrirlo y pulsar Iniciar o enviarle un mensaje.

¿Qué diferencia hay entre frontend y backend?+

El frontend es la parte visible que funciona en el navegador. El backend se ejecuta en el servidor, procesa solicitudes y guarda secretos como el token de la API.

¿Qué significa una respuesta HTTP 200?+

Indica que la solicitud HTTP se procesó correctamente a nivel de protocolo. En la Bot API también se debe revisar el campo JSON “ok” para confirmar el resultado de Telegram.

¿Por qué puede fallar el envío?+

Puede faltar el token, ser incorrecto el Chat ID, no haberse iniciado el bot, estar apagado el backend o existir un problema de conexión o permisos. Revisa la respuesta del servidor sin publicar credenciales.

¿Se puede publicar todo solamente en GitHub Pages?+

No para esta arquitectura: GitHub Pages sirve contenido estático y no ejecuta Node.js. El frontend puede publicarse allí, pero el backend debe alojarse por separado en un entorno compatible.
